# Напоминания пить воду

Небольшое приложение для Windows x64: показывает стакан воды и напоминает сделать перерыв на воду через заданный интервал.

## Скачать

[**Скачать последнюю версию для Windows x64 — Water.exe**](../../releases/latest/download/Water.exe) · [Все версии и примечания к выпускам](../../releases)

Скачайте `Water.exe` из раздела **Assets** последнего [GitHub Release](../../releases/latest) и запустите файл. Установка не нужна.

## Возможности

- Интервал отображается в **минутах**: от 15 минут до 24 часов. Кнопки **−** и **+** меняют его на 15 минут; значение также можно ввести вручную.
- Кнопка **«Я выпил(а) воду»** начинает отсчёт заново. **Пауза** приостанавливает напоминания.
- По окончании интервала появляется окно со звуком. Напоминание можно отложить на 10 минут.
- Закрытие окна сворачивает приложение в системный трей. Для завершения выберите **«Выход»** в контекстном меню значка.
- Настройки интервала и звука сохраняются между запусками. Старые настройки в часах переводятся в минуты автоматически.

## Требования

Windows 10 или 11, 64-разрядная версия. Для запуска требуется .NET Framework 4.x, который обычно уже установлен в Windows.

## Сборка из исходного кода

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт собирает `dist/Water.exe` штатным 64-разрядным компилятором .NET Framework и запускает проверки таймера и настроек. .NET SDK и загрузка пакетов не требуются.

Чтобы выпустить новую версию на GitHub, создайте Release и прикрепите `dist/Water.exe` к нему под именем `Water.exe`. После публикации ссылка для скачивания вверху этой страницы будет вести на последнюю версию.
